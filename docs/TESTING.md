# การตรวจระบบ AppNong Khai Trip_Hybrid_Mobile

ตรวจรอบล่าสุด 30 กันยายน 2026: TypeScript, Prettier, tests 8 ชุด, Expo Doctor 21/21 checks และ Metro export สำหรับ iOS/Android ผ่าน ผลเหล่านี้ไม่แทนการทดสอบบนมือถือจริง

## ขอบเขตการตรวจ

- TypeScript รวม unused imports และ formatting
- ชุดทดสอบ 8 ชุด: API, session, validation, ภาพ, migration, วันกลับและวันว่างระหว่างทริป
- Expo config ต้องใช้ชื่อใหม่และอ้างอิง assets ที่มีอยู่
- Metro export iOS/Android ตรวจ JavaScript/assets ไม่ใช่ native build
- ยังต้องทดสอบมือถือจริง กล้อง คลังภาพ SQLite offline และ notification
- ยังต้องเก็บ Profiler trace และ Accessibility audit ตาม Week 12
- ยังไม่ได้ยืนยัน clean clone/install/run และ native build ของรุ่นนี้

## แบบบันทึก

ระบุชื่อผู้ทดสอบ วันที่ รุ่นอุปกรณ์/OS, Expo Go หรือ Development Build และ commit ที่ใช้ ห้ามทำเครื่องหมายผ่านก่อนทดสอบจริง

| กรณี                                      | ผลที่คาดหวัง                                                  | ผลจริง  |
| ----------------------------------------- | ------------------------------------------------------------- | ------- |
| สแกน Expo และเปิด API                     | รายการสถานที่โหลดได้ ไม่มีจอขาว                               | รอทดสอบ |
| ค้นหา/ตัวกรอง/รายการโปรด                  | รายการถูกต้อง ปุ่มเพิ่มลงทริปอยู่เฉพาะหน้ารายละเอียด          | รอทดสอบ |
| เพิ่มสถานที่ก่อน Login                    | Login แล้วกลับมายังสถานที่เดิม                                | รอทดสอบ |
| ไม่มีทริปแล้วกดเพิ่ม                      | ไปสร้างทริป บันทึกแล้วมีสถานที่นั้นทันที                      | รอทดสอบ |
| มีทริปแล้วกดเพิ่ม                         | แสดงรายการทริปให้เลือก และป้องกันสถานที่ซ้ำ                   | รอทดสอบ |
| API โหลดทริปไม่ได้                        | แสดงข้อผิดพลาดและ retry ไม่สรุปว่าไม่มีทริป                   | รอทดสอบ |
| วันที่ไม่จริง เช่น 2026-02-31             | ไม่ส่งฟอร์มและแสดงข้อความ                                     | รอทดสอบ |
| แก้ชื่อ/เวลา เรียง/นำสถานที่ออก           | เปลี่ยนใน UI และยังอยู่หลัง restart                           | รอทดสอบ |
| ทริปไม่มีสถานที่                          | มีคำแนะนำเพิ่มสถานที่ ไม่เปิดแผนที่ว่าง                       | รอทดสอบ |
| แผนที่หลายหมุด                            | เห็นหมุดทั้งหมดพร้อมหมายเลขในชื่อ                             | รอทดสอบ |
| ถ่ายภาพในทริป A                           | รูปอยู่ในอัลบั้ม A ไม่ปนทริป B                                | รอทดสอบ |
| สลับกล้อง หน้า/หลัง และกลับจาก background | กล้องพร้อมใช้งานและไม่ถ่ายซ้ำ                                 | รอทดสอบ |
| Camera denied / cannot ask again          | กลับทริปหรือเปิด Settings ได้                                 | รอทดสอบ |
| เลือกรูปจากคลังแล้วยกเลิก                 | ข้อมูลทริปและรูปเดิมยังอยู่                                   | รอทดสอบ |
| เลือกโทนแล้วบันทึก                        | รูปในอัลบั้มและไฟล์ที่บันทึกมีโทนตรง preview                  | รอทดสอบ |
| ปิดเน็ตก่อนบันทึกรูป                      | บันทึกในเครื่องและแสดงรอส่ง                                   | รอทดสอบ |
| ปิดแอป/เปิดใหม่ขณะ offline                | รูปที่รอส่งและทริปที่เคยโหลดกลับมาได้ เมื่อ session ยังใช้ได้ | รอทดสอบ |
| กลับ online/ดึงข้อมูลใหม่                 | รูปถูกส่งไป API ครั้งเดียวและสถานะรอส่งหาย                    | รอทดสอบ |
| บันทึกรูปลงคลังมือถือหลายครั้ง            | ทำได้จากรูปที่อยู่ในอัลบั้ม ขอสิทธิ์เมื่อกดเท่านั้น           | รอทดสอบ |

| Logout                                    | หน้าทริปไม่แสดงข้อมูลบัญชีเดิม                                | รอทดสอบ |

| VoiceOver หรือ TalkBack                   | Flow หลักอ่านชื่อ บทบาท และสถานะปุ่มได้ตามลำดับ               | รอทดสอบ |

## คำสั่ง

```bash
npm run typecheck
npm test
npm run format:check
npx expo-doctor
npx expo export --platform ios --platform android --output-dir /tmp/nongkhai-trip-export
```

API tests ใช้โฟลเดอร์ชั่วคราวและ port สุ่ม ไม่แก้ข้อมูลใน `server/data` ส่วนการทดสอบ clean clone ต้องใช้ repository ที่ push รุ่นนี้แล้ว
